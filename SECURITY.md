# Security / Bezpieczeństwo

## English

Do not publish sensitive measurement data, credentials or proprietary neural-network weights in issues. Report a security issue privately to the repository owner through GitHub before public disclosure.

## Polski

Nie publikuj w zgłoszeniach poufnych danych pomiarowych, danych uwierzytelniających ani zastrzeżonych wag sieci neuronowych. Problem bezpieczeństwa zgłoś prywatnie właścicielowi repozytorium przez GitHub przed publicznym ujawnieniem.
