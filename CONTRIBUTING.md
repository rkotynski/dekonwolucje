# Contributing / Współpraca

## English

1. Create a branch from `main`.
2. Keep source-code comments, docstrings, configuration keys and internal identifiers in English.
3. Add both the English GUI source string and its Polish translation for every new visible control or message.
4. Add or update tests.
5. Run `pytest` before opening a pull request.

Please describe numerical-model changes explicitly, especially boundary conditions, PSF normalization, FFT centering and data types.

## Polski

1. Utwórz gałąź od `main`.
2. Komentarze, docstringi, klucze konfiguracji i identyfikatory wewnętrzne zapisuj po angielsku.
3. Dla każdego nowego elementu lub komunikatu GUI dodaj angielski tekst źródłowy i polskie tłumaczenie.
4. Dodaj albo uaktualnij testy.
5. Przed zgłoszeniem pull requestu uruchom `pytest`.

Zmiany modelu numerycznego opisuj jawnie, szczególnie warunki brzegowe, normalizację PSF, centrowanie FFT i typy danych.
