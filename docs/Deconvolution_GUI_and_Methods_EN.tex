\section{Purpose and scope}
The program is a desktop research application for restoration of grayscale images blurred by a point-spread function (PSF) and contaminated by noise. It supports non-blind deconvolution with a supplied PSF and blind deconvolution in which both the latent image and the PSF are updated. The GUI separates source-data preparation, committed PSF selection, algorithm parameters, and result assessment.

The same committed calculation image and calculation PSF are used by all algorithms, synthetic degradation, reblur metrics, and blind-PSF initialization. NumPy/SciPy methods and PyTorch variants are available. PyTorch uses \code{float32} by default and can use CUDA when requested and available.

\section{Forward model and boundary conditions}
Let $f[m,n]$, $0\leq m<M$, $0\leq n<N$, be the unknown image, let $h[u,v]$, $0\leq u<M_h$, $0\leq v<N_h$, be the calculation PSF, let $g$ be the measured image, and let $n$ denote additive noise. The committed PSF is nonnegative and normalized so that $\sum_{u,v}h[u,v]=1$.

For clarity, $*$ denotes convolution rather than pointwise multiplication. The full zero-boundary linear convolution used by the program is defined by
\[
(h*_{\rm lin} f)[r,s]
=\sum_{u=0}^{M_h-1}\sum_{v=0}^{N_h-1}
 h[u,v] \,\widetilde f[r-u,s-v],
\]
where $\widetilde f[a,b]=f[a,b]$ inside the image and $\widetilde f[a,b]=0$ outside it. Its full result has size $(M+M_h-1)\times(N+N_h-1)$. The default image-sized forward operator is the centered \emph{same} crop
\[
\mathcal H_{\rm lin}f=C_{\rm same}(h*_{\rm lin}f),\qquad
(C_{\rm same}y)[m,n]=y[m+s_y,n+s_x],
\]
with $s_y=\lfloor(M_h-1)/2\rfloor$ and $s_x=\lfloor(N_h-1)/2\rfloor$. This is the convention of \code{scipy.signal.fftconvolve(..., mode="same")}; it is symmetric for odd kernels and intentionally one-sample asymmetric for even kernels.

The compact notation $\mathcal H f$ therefore means ``convolve $f$ with the PSF $h$ using the boundary and cropping convention assigned to $\mathcal H$''. It is matrix--vector notation for a linear operator, not a pointwise product. The discrete observation model is
\begin{equation}g=\mathcal{H}f+n.\end{equation}
The project deliberately distinguishes two choices of $\mathcal H$.

\subsection{Zero-boundary linear convolution}
Most iterative methods and synthetic disturbance generation use $\mathcal H=\mathcal H_{\rm lin}$ as defined above. The FFT implementation evaluates the full linear convolution on a canvas of size
\begin{equation}(M+M_h-1)\times(N+N_h-1).\end{equation}
The discrete complex inner product used here is
\[
\langle x,y\rangle=\sum_{m,n}\overline{x[m,n]}\,y[m,n].
\]
The adjoint $\mathcal{H}^{*}$ is defined by
\[
\langle\mathcal{H}x,y\rangle=\langle x,\mathcal{H}^{*}y\rangle.
\]
If $A$ is the matrix representation of $\mathcal H$, then $\mathcal H^{*}$ is represented by the Hermitian transpose $A^{*}=\overline{A}^{\mathsf T}$. Because the spatial PSF and the crop/embedding operations used here are real, this reduces to the ordinary transpose $A^{\mathsf T}$, but it is still the adjoint of the complete forward operator, not merely the elementwise conjugate of the PSF samples. The corresponding adjoint $\mathcal{H}_{\rm lin}^{*}$ is therefore the transpose of the exact zero-boundary convolution followed by the centered crop, including the asymmetric convention needed for even kernels.

\subsection{Circular FFT model}
The closed-form Wiener inverse uses circular convolution because this operator is diagonal in the two-dimensional discrete Fourier basis. NumPy/SciPy and PyTorch are used with their default \code{norm="backward"} convention. For an $M\times N$ array $x$, the transform pair is
\begin{align*}
X[k,\ell]=\calF_{M,N}\{x\}[k,\ell]
&=\sum_{m=0}^{M-1}\sum_{n=0}^{N-1}
 x[m,n]\exp\!\left[-2\pi i\left(\frac{km}{M}+\frac{\ell n}{N}\right)\right],\\
x[m,n]=\calF_{M,N}^{-1}\{X\}[m,n]
&=\frac{1}{MN}\sum_{k=0}^{M-1}\sum_{\ell=0}^{N-1}
 X[k,\ell]\exp\!\left[2\pi i\left(\frac{km}{M}+\frac{\ell n}{N}\right)\right].
\end{align*}
Thus the forward DFT is unnormalized and the factor $1/(MN)$ occurs only in the inverse DFT. With this pair, neither linear nor circular convolution needs an extra numerical scale factor. In particular, if $P=M+M_h-1$, $Q=N+N_h-1$, and $f_{P,Q}$ and $h_{P,Q}$ are the two arrays zero-padded to the full linear-convolution canvas, then
\[
h*_{\rm lin}f
=\calF_{P,Q}^{-1}\!\left\{\calF_{P,Q}\{h_{P,Q}\}\,\calF_{P,Q}\{f_{P,Q}\}\right\}.
\]
The implementation may use the equivalent real-input pair \code{rfft2}/\code{irfft2}; it has the same normalization.

To construct the circular PSF array $h_0$, the compact calculation PSF is zero-embedded in an $M\times N$ array and rolled by $-\lfloor M_h/2\rfloor$ and $-\lfloor N_h/2\rfloor$. This places the kernel-array index $(\lfloor M_h/2\rfloor,\lfloor N_h/2\rfloor)$ at the FFT origin, exactly as in the program. Circular convolution is then
\[
(h_0\circledast f)[m,n]
=\sum_{u=0}^{M-1}\sum_{v=0}^{N-1}
 h_0[u,v]f[(m-u)\bmod M,(n-v)\bmod N],
\]
and it satisfies $\calF\{h_0\circledast f\}=\calF\{h_0\}\,\calF\{f\}$. With
\begin{equation}G=\calF\{g\},\qquad H=\calF\{h_0\},\end{equation}
where $h_0$ is the zero-embedded, origin-shifted PSF array defined above. Here $H$ is an $M\times N$ array of complex Fourier coefficients, not the spatial-domain matrix representation of $\mathcal H$. For any complex array $Z$, the notation $Z^{*}$ means elementwise complex conjugation,
\[
Z^{*}[k,\ell]=\overline{Z[k,\ell]},\qquad |Z|^2=Z^{*}Z,
\]
where the final product is pointwise. Equivalently, if circular convolution is represented in the Fourier basis by the diagonal matrix $\operatorname{diag}(H)$, its Hermitian adjoint is $\operatorname{diag}(H^{*})$. Thus the spectral conjugate $H^{*}$ is the Fourier-domain representation of the adjoint circular-convolution operator; it should not be confused with taking only an elementwise conjugate of the full spatial operator matrix.
\begin{equation}\mathcal{H}_{\rm circ}f=\operatorname{Re}\left\{\calF^{-1}[H\calF\{f\}]\right\}.\end{equation}
The real part discards only the small imaginary round-off residual expected for real input arrays.

Circular convolution wraps samples across opposite borders: signal leaving the right or lower edge re-enters at the left or upper edge. Zero-boundary linear convolution instead assumes no signal outside the image and discards the outer part when the \emph{same} crop is taken.
\boxnote{Linear and circular boundary models are not identical. A Wiener result can differ near the borders from an iterative result even when both use the same numerical PSF.}

\section{Committed calculation image and PSF}
\subsection{Source arrays and reset}
The program retains the image and PSF loaded from disk or generated in the GUI as source arrays. \textbf{Reset thresholds / PSF selection} restores these sources. In parallel it stores one committed pair: the thresholded calculation image and the thresholded, cropped, nonnegative, unit-sum calculation PSF.

\subsection{Image and PSF floors}
For nonnegative data $x$ with maximum $m$ and floor $T$, the applied mapping is
\begin{equation}
x_T=\begin{cases}0,&x\leq T,\\[1mm]m\dfrac{x-T}{m-T},&x>T,\end{cases}
\end{equation}
for $0<T<m$. Thus the background is removed and the surviving range is stretched to the original maximum. The PSF floor is specified as a fraction $q$ of the source PSF peak, $T_p=q p_{\max}$.

\subsection{Rectangular PSF selection and normalization}
After thresholding, all full-array samples outside the accepted red rectangle are set to zero. A compact kernel of height $M_h$ and width $N_h$ is extracted around the selected center. Missing samples are zero-padded when the rectangle extends beyond the source array. The calculation PSF is
\begin{equation}
h[u,v]\leftarrow\frac{\max(h_{\rm crop}[u,v],0)}{\sum_{u,v}\max(h_{\rm crop}[u,v],0)},
\end{equation}
so that $h\geq0$ and $\sum h=1$.

Pending slider and rectangle changes do not alter the histogram or calculation data until \textbf{Apply thresholds / PSF selection now} is pressed. The rectangle can be moved, resized by edges or corners, or scaled about its center with the mouse wheel.

\subsection{Automatic initial support}
The initial support suggestion estimates the border median $b$ and a robust noise scale
\begin{equation}\sigma_b\approx1.4826\,\operatorname{median}(|p_{\partial}-b|).\end{equation}
Pixels are active when
\begin{equation}p[u,v]>\max\left(b+3\sigma_b,10^{-2}p_{\max}\right).\end{equation}
Width and height are estimated independently, which is useful for motion blur or astigmatic PSFs. The proposal remains editable.

\section{Wiener filtering}
Every Wiener stage uses explicit FFT and inverse FFT operations. The spectral minimum-mean-square-error construction follows the classical Wiener framework~\cite{Wiener1949}. For scalar $K$ and optional normalized noise spectrum $N[k,\ell]$,
\begin{equation}
\widehat F[k,\ell]=\frac{H^*[k,\ell]G[k,\ell]}{|H[k,\ell]|^2+K N[k,\ell]},
\end{equation}
In this equation, $H^*[k,\ell]=\overline{H[k,\ell]}$ is the elementwise complex conjugate of the PSF spectrum. It is also the diagonal Fourier-basis representation of the adjoint of circular convolution by $h_0$.
followed by
\begin{equation}\widehat f=\operatorname{Re}\{\calF^{-1}[\widehat F]\}.\end{equation}
The obsolete magnitude-of-IFFT output was removed because it is nonlinear and converts negative ringing into positive intensity.

For fixed PSF, generalized cross-validation uses the leverage
\begin{equation}L_H=\frac{|H|^2}{|H|^2+KN},\qquad R_H=1-L_H,
\end{equation}
and a normalized cost of the form
\begin{equation}
\operatorname{GCV}(K)=\frac{\langle|R_HG_c|^2\rangle/\langle|G_c|^2\rangle}{\langle R_H\rangle^2},
\end{equation}
where $G_c$ is the spectrum of the mean-centered measured image. The parameter-selection principle is related to generalized cross-validation~\cite{Golub1979}. GCV selects $K$ for a fixed PSF; it is not used as unrestricted proof that a strongly thresholded PSF is physically correct.

\section{Richardson--Lucy family}
\subsection{Classical Richardson--Lucy}
The multiplicative update is
\begin{equation}
\label{eq:rl-update}
f^{(t+1)}=f^{(t)}\odot\mathcal{H}_{\rm lin}^{*}\left[\frac{g}{\mathcal{H}_{\rm lin}f^{(t)}+\varepsilon}\right].
\end{equation}
The update follows the independent formulations of Richardson and Lucy~\cite{Richardson1972,Lucy1974}. The implementation uses the exact adjoint of the zero-boundary linear \emph{same} operator. Initialization can be a constant image or a Wiener result. Nonnegativity, TV processing, and a neural denoiser can be applied.

\subsection{Richardson--Lucy--Wiener}
This experimental hybrid performs an RL update and then a Wiener operation in every iteration. It combines the parent Richardson--Lucy and Wiener methods~\cite{Richardson1972,Lucy1974,Wiener1949}; it is a program-specific hybrid rather than a reproduction of a single original algorithm.

\subsection{Richardson--Lucy--Rosen}
The implementation keeps the Richardson--Lucy forward prediction and ratio, but replaces the adjoint back-projection factor in Eq.~\eqref{eq:rl-update}. At iteration $t$ it first evaluates
\[
r^{(t)}=\frac{g}{\mathcal H_{\rm lin}f^{(t)}+\varepsilon},
\qquad R^{(t)}=\calF\{r^{(t)}\}.
\]
The compact PSF is embedded and shifted to the FFT origin on the image-sized grid, producing $h_0$ and its spectrum $H=\calF\{h_0\}$. Equation~\eqref{eq:rosen-spectrum} is then used with $F_1=R^{(t)}$ and $F_2=H$:
\begin{equation}
\label{eq:rosen-spectrum}
C_{L,M}^{(t)}=(|R^{(t)}|+\varepsilon)^L(|H|+\varepsilon)^M
\exp\!\left[i\left(\arg R^{(t)}-\arg H\right)\right].
\end{equation}
The inverse transform gives a real spatial correlation map,
\[
c_{L,M}^{(t)}=\operatorname{Re}\!\left\{\calF^{-1}\!\left[C_{L,M}^{(t)}\right]\right\}.
\]
The code then applies a global offset removal and peak normalization,
\[
b_{L,M}^{(t)}=
\frac{c_{L,M}^{(t)}-\min c_{L,M}^{(t)}}
{\max\!\left(\max(c_{L,M}^{(t)}-\min c_{L,M}^{(t)}),\varepsilon\right)},
\]
and replaces the classical factor $\mathcal H_{\rm lin}^{*}r^{(t)}$ in Eq.~\eqref{eq:rl-update} by $b_{L,M}^{(t)}$. The actual multiplicative step is therefore
\[
f^{(t+1)}=f^{(t)}\odot\left(b_{L,M}^{(t)}+\varepsilon\right),
\]
followed, when enabled, by TV processing, neural denoising, and projection onto the nonnegative cone.

Ignoring $\varepsilon$ and the spatial min--max normalization, the special case $L=M=1$ gives
\[
C_{1,1}^{(t)}=|R^{(t)}||H|
\exp\!\left[i(\arg R^{(t)}-\arg H)\right]
=R^{(t)}H^{*}.
\]
Thus it reduces to ordinary circular cross-correlation of the Richardson--Lucy ratio with the PSF. It is nevertheless \emph{not exactly identical} to the classical update in Eq.~\eqref{eq:rl-update}: the latter uses the exact adjoint of the zero-boundary linear \emph{same} operator, whereas the Rosen correction uses image-sized circular FFT correlation and is subsequently offset and normalized to the interval $[0,1]$. Consequently, the GUI preset $L=M=1$ aligns the nonlinear exponents with ordinary correlation, but does not remove these boundary-model and normalization differences.

Values $L,M<1$ compress spectral magnitudes and increase the relative influence of phase. If relaxation toward one is enabled, the exponents are updated after each completed iteration according to
\[
L_{t+1}=\rho L_t+(1-\rho),\qquad
M_{t+1}=\rho M_t+(1-\rho),\qquad 0\leq\rho\leq1,
\]
so they approach one for $\rho<1$. The construction is inspired by nonlinear reconstruction and the Lucy--Richardson--Rosen literature~\cite{Smith2022,Anand2022}; the exact circular correlation, min--max normalization, and relaxation controls are implementation-specific.

\section{Landweber, Kaczmarz, and Adam methods}
\subsection{Landweber}
The classical update is gradient descent on the least-squares data term, following Landweber's iteration for first-kind integral equations~\cite{Landweber1951}:
\begin{equation}
f^{(t+1)}=f^{(t)}+\alpha\mathcal{H}_{\rm lin}^{*}(g-\mathcal{H}_{\rm lin}f^{(t)}).
\end{equation}
The Wiener-preconditioned version transforms the adjoint residual $d$ as
\begin{equation}
\widetilde d=\operatorname{Re}\left\{\calF^{-1}\left[\frac{\calF\{d\}}{|H|^2+KN}\right]\right\}
\end{equation}
and applies $f^{(t+1)}=f^{(t)}+\alpha\widetilde d$.

\subsection{Block Kaczmarz}
\subsubsection*{Relation to the classical Kaczmarz method}
Writing the linear deconvolution problem as $Af=g$, the classical row-action method introduced by Kaczmarz~\cite{Kaczmarz1937} updates one equation at a time. For row $a_i^{\mathsf T}$ it is
\begin{equation}
f^{(j+1)}=f^{(j)}+\omega\,
\frac{g_i-a_i^{\mathsf T}f^{(j)}}{\norm{a_i}_2^2}\,a_i,
\end{equation}
where $\omega$ is a relaxation factor. The update is an orthogonal projection for $\omega=1$ and an under- or over-relaxed projection otherwise. A formal block version using a group of rows $A_B$ is
\begin{equation}
f^{+}=f+\omega A_B^{\mathsf T}
\left(A_BA_B^{\mathsf T}+\eta I\right)^{-1}(g_B-A_Bf),
\end{equation}
with optional stabilization $\eta\geq0$. For an image convolution problem, however, explicitly storing $A$ or repeatedly solving the block normal equations is expensive.

\subsubsection*{Approximate ART-style implementation used in the program}
The implemented method is therefore an \emph{approximate block Kaczmarz/ART scheme}, not an exact algebraic block projection. Its blockwise image-reconstruction interpretation is related to algebraic reconstruction techniques (ART)~\cite{Gordon1970}. Let $\mathcal H_{\rm lin}$ be the zero-boundary linear convolution operator and let $P_b$ select an observation block. At the start of each outer iteration the blurred estimate is evaluated once,
\begin{equation}y=\mathcal H_{\rm lin}f.
\end{equation}
For every selected block $b$, the local residual is
\begin{equation}r_b=P_b(g-y).
\end{equation}
A separable smooth window $W_b$ may be applied to reduce seams. The code uses a raised Hann window whose one-dimensional weights are $0.25+0.75w_{\rm Hann}$, so boundary samples retain nonzero weight.

In the default stabilized full-sweep mode, all selected residual blocks are accumulated on the observation grid and divided pointwise by their accumulated coverage:
\begin{equation}
\widetilde r=
\frac{\sum_{b\in\mathcal B}P_b^{\mathsf T}(W_b\odot r_b)}
{\sum_{b\in\mathcal B}P_b^{\mathsf T}W_b},
\end{equation}
where division is performed only where the denominator is positive. One global adjoint correction is then formed,
\begin{equation}
\Delta f=\omega\,
\frac{\mathcal H_{\rm lin}^{*}\widetilde r}
{\max(\sum_{u,v}h[u,v]^2,\varepsilon)}.
\end{equation}
This coverage-normalized sweep retains the row-action idea---only selected observation blocks contribute---while suppressing brightness jumps and periodic block-grid artifacts that arose when every local correction was applied independently.

The optional legacy mode back-projects each block separately and retains only the corresponding reconstruction block. Overlapping contributions are normalized by the squared smooth-window weights. It is useful mainly for comparison because it is more sensitive to block boundaries.

\subsubsection*{Block geometry and ordering}
The current implementation uses square observation blocks of side $B$. Without overlap the stride is $B$; with overlap it is $\max(1,\lfloor B/2\rfloor)$. Boundary starts are always included, so the complete image is covered. The user can choose:
\begin{itemize}
\item a full sweep over every block or only a specified number of blocks per outer iteration;
\item deterministic cyclic order or a reproducible randomized order;
\item overlapping or non-overlapping blocks;
\item a shifted block lattice between full sweeps, which changes the block boundaries and reduces stationary grid artifacts;
\item smooth block weighting or uniform weights.
\end{itemize}

\subsubsection*{Stability controls and optional processing}
Before application, the raw update can be clipped relative to the current signal scale,
\begin{equation}
s=\max\left(Q_{0.99}(|f|),Q_{0.99}(|g|),10^{-6}\right),\qquad
\Delta f\leftarrow\operatorname{clip}(\Delta f,-\rho s,\rho s),
\end{equation}
where $\rho$ is the maximum update fraction. A damping parameter $\beta\in[0,1]$ then gives
\begin{equation}
f^{+}=(1-\beta)f+\beta(f+\Delta f).
\end{equation}
The estimate may subsequently be projected onto nonnegative values and passed through the optional TV preconditioner or neural denoiser. Wiener initialization is also available when explicitly enabled.

The method is most useful when blockwise data access, artifact diagnosis, or comparison with ART-style reconstruction is of interest. It should not be interpreted as an exact solution of the block projection equations, and its parameters are coupled: increasing overlap or the number of visited blocks generally requires reconsidering relaxation, damping, and the update limit.

\subsection{PyTorch Adam TV-MAP}
The non-blind Adam method minimizes
\begin{equation}J(f)=\frac12\norm{\mathcal{H}_{\rm lin}f-g}_2^2+\lambda_f\operatorname{TV}(f)
\end{equation}
with automatic differentiation. The TV prior follows the edge-preserving Rudin--Osher--Fatemi model~\cite{Rudin1992}, while parameter updates use Adam~\cite{Kingma2015}. Candidate parameter sets can be processed in batches. Nonnegativity is enforced by projection when selected.

\section{Blind deconvolution}
\subsection{Blind Richardson--Lucy}
Blind RL alternates the image update with a PSF update obtained from correlation of the current image estimate and the relative-blur ratio. Alternating Richardson--Lucy blind deconvolution was described by Fish \emph{et al.}~\cite{Fish1995}. The PSF is cropped to the Tab-2 dimensions, projected to nonnegative values, and normalized after each update. Initialization can use the current calculation PSF or a rectangular Gaussian. Optional rotational projection imposes symmetry.

\subsection{Blind Adam TV-MAP}
The blind PyTorch method jointly minimizes
\begin{equation}
J(f,h)=\frac12\norm{h*f-g}_2^2+\lambda_f\operatorname{TV}(f)+\lambda_h\operatorname{TV}(h).
\end{equation}
After every Adam step the PSF is projected onto $h\geq0$ and $\sum h=1$, with optional rotational symmetry. Separate learning rates are used for image and PSF. This is an implementation-specific joint MAP construction built from the TV and Adam components~\cite{Rudin1992,Kingma2015}, rather than a reproduction of one canonical blind-deconvolution paper.

\boxnote{Blind deconvolution is intrinsically non-unique. PSF width, image sharpness, noise, regularization, initialization, and stopping iteration can compensate for one another.}

\section{Metrics and best-iteration selection}
With an independent reference, the program evaluates MSE, PSNR, and SSIM. For normalized peak value one,
\begin{equation}\operatorname{PSNR}=10\log_{10}(1/\operatorname{MSE}).\end{equation}
Without a reference it uses a composite no-reference criterion including reblur consistency, intensity preservation, total variation, and residual whiteness. For candidate $\widehat f$ the residual is
\begin{equation}r=\mathcal{H}_{\rm lin}\widehat f-g.\end{equation}
Residual whiteness is estimated from short-range normalized autocorrelations of $r-\bar r$. Metrics for the history are computed in batches and cached, so returning to the best iteration does not rerun postprocessing.

\section{Auto tuning and cancellation}
Auto evaluates parameter candidates, using batched implementations when possible. Parameters belonging to optional stages that were disabled when tuning started are frozen. Auto calculations run in an isolated numerical process. \textbf{Cancel Auto} first requests cooperative stopping; if the current numerical iteration does not return within five seconds, the worker process is terminated while the Qt GUI process remains alive.

\section{Batch processing and CUDA}
PyTorch variants operate on stacks of candidates where possible. The key choices are: default \code{float32}; cached spectra for fixed PSFs; differentiable FFT convolution for changing PSFs; memory-limited chunking; grouping of blind-history frames by PSF shape; and CPU fallback when CUDA is unavailable or memory allocation fails. GPU acceleration is most useful for large images, many iterations, and candidate batches.

\subsection{Automatic parameter selection}
The parameter-selection logic used by the GUI is also available synchronously through the public API.  A typical call is
\begin{lstlisting}[language=Python]
from deconv.api import AutoTuneOptions, auto_deconvolve

tuning = auto_deconvolve(
    disturbed, psf,
    algorithm="Richardson-Lucy",
    reference=reference,       # optional independent truth
    params={
        "iterations": 20,
        "epsilon": 1e-8,
        "begin_with_wiener": False,
    },
    auto_options=AutoTuneOptions(
        strategy="quadratic",
        use_torch_equivalent=True,
        tune_boolean=False,
        tune_categorical=False,
    ),
    progress_callback=print,
)
restored = tuning.deconvolution_result.image.data
print(tuning.best_params)
\end{lstlisting}
\code{auto\_tune\_parameters} returns an \code{AutoTuningResult} and performs no final run unless \code{run\_best=True}; \code{auto\_deconvolve} always executes the accepted parameter set.  The returned object contains the requested and proxy algorithms, initial and accepted parameters, initial and final scores, candidate count, elapsed time, status text, the evaluated-candidate history, and the optional \code{DeconvolutionResult}.

When an independent \code{reference} is supplied, Auto maximizes the best PSNR found in each candidate's stored iteration history.  Without a reference, ordinary Wiener tuning minimizes generalized cross-validation (GCV).  The other methods maximize the negative of the same no-reference cost used by the GUI, which combines reblur consistency, normalized total variation, intensity preservation, and short-range residual whiteness.

Two strategies are exposed.  The default \code{quadratic} strategy performs two short coordinate passes.  Each numerical coordinate is evaluated below, at, and above the current value; when the three finite scores are locally concave, a parabola is fitted and its vertex is tested.  Wiener $K$ is handled separately by a broad logarithmic scan followed by two narrower log-space refinements.  The \code{full\_batched} strategy constructs a bounded local Cartesian pool and uses \code{run\_batch} or \code{score\_batch} when the selected implementation supports batched Auto.

As in the GUI, the activation state of optional processing stages is frozen before candidate generation.  Thus a disabled Wiener initializer, denoiser, or optional TV preconditioner cannot be enabled temporarily, and its hidden dependent parameters remain unchanged.  Numeric, independent Boolean, categorical, denoiser, TV, and $K$ tuning for an already active Wiener initializer are controlled independently through \code{AutoTuneOptions}.  When PyTorch is available, a plain algorithm can be tuned with its Torch-batched equivalent and then validated on the originally requested implementation.  Setting \code{use\_torch\_equivalent=False} disables this proxy.

The synchronous API accepts a \code{progress\_callback} and an optional \code{stop\_event} with an \code{is\_set()} method.  Cancellation is checked between candidate evaluations.  Unlike the GUI's isolated numerical worker, the API does not terminate the caller process if one individual FFT/CUDA iteration blocks for a long time.

\subsection{Advanced execution hooks}
Iterative methods accept \code{\_iteration\_callback} and \code{\_stop\_event}.  The callback receives the current and total iteration numbers; a set event requests cooperative stopping after the current iteration.  These underscored names are advanced execution hooks and may evolve more readily than the main API.  GUI classes and application-state objects are deliberately excluded from the public numerical API.

\section{Limitations and interpretation}
\begin{itemize}
\item Wiener uses a circular model, while most iterative methods use zero-boundary linear convolution.
\item Joint PSF-floor and $K$ selection without a reference is heuristic; GCV selects regularization for a fixed PSF but does not uniquely identify the physical PSF.
\item Blind methods are non-convex and depend on support, initialization, constraints, and stopping.
\item Display levels alter visualization only, not stored reconstruction values.
\item Fine reconstructed structure should be validated against independent measurements or simulations.
\end{itemize}
