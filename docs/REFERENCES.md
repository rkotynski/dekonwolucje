# Method references / Literatura metod

The English PDF contains clickable citations to original or classical sources for Wiener filtering, GCV, Richardson-Lucy, Landweber, Kaczmarz/ART, total variation, Adam, blind Richardson-Lucy and nonlinear/Lucy-Richardson-Rosen reconstruction.

Hybrid methods and stabilization variants implemented in the program are not always exact reproductions of a single paper. In those cases the documentation cites the parent methods and explicitly labels the implementation-specific construction.

Polski: angielski PDF zawiera klikalne odwołania do prac oryginalnych lub klasycznych dotyczących filtru Wienera, GCV, metod Richardsona-Lucy'ego, Landwebera, Kaczmarza/ART, wariacji całkowitej, Adama, ślepej metody Richardsona-Lucy'ego oraz rekonstrukcji nieliniowej/Lucy-Richardson-Rosen.

Metody hybrydowe i warianty stabilizacji zaimplementowane w programie nie zawsze są dokładnym odtworzeniem pojedynczej publikacji. W takich przypadkach dokumentacja odwołuje się do metod bazowych i wyraźnie oznacza elementy specyficzne dla implementacji.
