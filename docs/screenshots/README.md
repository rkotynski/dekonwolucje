# Screenshots / Zrzuty ekranu

The four screenshots used by the English PDF are included in this directory:

- `01-gui-overview.png` - main workflow, committed calculation data and language selector;
- `02-psf-preparation.png` - Tab 2 thresholds and editable PSF support;
- `03-kaczmarz-settings.png` - Block Kaczmarz parameters;
- `04-result-history.png` - result history, criteria and display levels.

The LaTeX source includes them automatically. Replacement files should keep the same names.
